# ADR-0004 — Distribuição como PWA instalável

**Data:** 2026-08-19 · **Status:** Aceita

## Contexto
A landing do cliente já anuncia **"DOWNLOAD • WINDOWS"**, **"DOWNLOAD • ANDROID"** e
"Versão mais recente disponível". A plataforma precisa cumprir essa promessa. Além disso,
o uso real é celular na mesa, às vezes sem internet decente.

## Alternativas
1. **PWA instalável** — uma base React. Instala na tela inicial do Android e como app no Windows. Funciona offline. Sem loja, sem build nativo.
2. **PWA + wrapper desktop** (Electron/Tauri) — gera um `.exe` de verdade, ao custo de build, assinatura de código e um canal de atualização extra.
3. **Nativo** (React Native / Capacitor + Play Store) — maior custo e manutenção; só vale por presença em loja.

## Decisão
**PWA instalável**, com uma única base de código.

## Consequências
- Cumpre "Windows e Android" sem manter três bases.
- Atualização é instantânea — sem revisão de loja, sem usuário em versão velha.
- Offline vem de graça pelo service worker, o que atende a sessão presencial sem internet.
- **Não** existe um arquivo `.exe` para baixar. Se o cliente insistir nisso, o caminho é
  a alternativa 2 e o custo é conhecido. → **Pergunta P1.**
- Sem presença em loja de aplicativos, o que custa descoberta orgânica. A distribuição
  hoje é pelo Discord e pelo site, onde isso importa pouco.
- A tela de download do site precisa ser reescrita para explicar a instalação do PWA, que
  é menos familiar que um instalador.
